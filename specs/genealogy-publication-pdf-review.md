## 发现与修正

| 原样张的问题 | 修正与复验 |
| --- | --- |
| 现代第 2/15 页、传统第 2/21 页为空谱序或空附录 | 空章节、目录项及书签同步略过；全选空章节时返回可操作错误 |

| 没有亲子世代依据的赵雯与另一位林晨被标成第一世 | 两人标为“世代未定”，生成 2 条校对提示；没有猜测配偶世代或合并重名人物 |
| 传统短字段各占一列、人物及来源末尾形成稀疏续页 | 短字段连成连续竖排段落；短记录整体分页，长记录保留续页上下文 |
| 现代第 12-13 页事件标题与正文断开，2012 年以前的事件排在 2024 年以后 | 短事件整体排版；仅有日期上界时用上界排序，保留模糊表达并显示排序说明 |
| 在世人物出现“卒：未知”；关系日期并列而不说明起止 | 在世且无死亡记录时省略卒年；关系、履历和称谓日期明确起止 |
| 空引文定位显示“原资料定位：。”，部分关联来源没有随记录打印 | 空定位省略；已有来源关联仍列出来源名和内部链接 |
| 无图封面像正文首页，视觉层次不足 | 现代封面居中排题，传统封面使用竖排题签；保留长标题及图片封面的完整内容 |
| 媒体样本附录先生成一张只有标题的空页 | 附录章节直接落在第一张选中原 PDF 页面，目录目标同步修正 |
