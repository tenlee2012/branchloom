# 有谱（Branchloom）

> 让家族记忆被认真记录，也能被长久保存。

有谱是一款本地优先的家谱与人物关系管理应用。它帮助个人和家庭整理人物、关系、事件与史料，并用家谱树、人物档案和时间线呈现一段段家族故事。

有谱无需注册账号，离线也能使用。你的资料默认保存在自己的设备上，可以随时备份、迁移，也可以选择同步到自己的私有`Github仓库`。

## 为什么做有谱

家谱不只是一张关系图。姓名的变化、迁徙的经历、家庭成员的回忆，以及一份旧档案的出处，都是值得保留的历史。

有谱希望做到：

- **资料属于用户**：不把联网、注册或云服务作为使用前提。
- **尊重真实家庭**：支持多样的姓名、亲属和伴侣关系，不替用户简化家庭经历。
- **重视依据**：让来源、引文和附件与人物及事件一起保存。
- **便于长期保存**：支持完整备份和开放、可迁移的数据格式，避免人还在而网站已死的尴尬。
- **操作清楚可控**：重要修改提供明确反馈，危险操作要求确认。

## 主要功能

- 创建和管理多个家谱项目。
- 记录人物的多种姓名、生卒信息、生平、职业经历、备注和头像。
- 整理亲生、收养、继亲、监护及多种伴侣关系。
- 从家谱树、人物列表和时间线浏览家庭资料。
- 记录地点、家庭事件、史料来源、引文和本地附件。
- 搜索人物，检查日期异常、关系问题、重复人物和缺失附件。
- 比较并合并疑似重复的档案。
- 创建可恢复的历史快照。
- 导入和导出包含附件的 `.blp` 完整项目包。
- 支持连接 GitHub 私有仓库，将项目数据备份并同步自己的项目，并且原生支持 git 版本管理，方便回切。

## 数据与隐私

- 家谱资料默认只保存在本机。
- 不注册账号也可以创建、编辑、查看和备份项目。
- GitHub 同步完全可选，不影响本地使用。
- 访问凭据不会写入家谱项目或导出的项目包。
- `.blp` 项目包包含完整资料和附件，可用于备份、迁移与分享。
- 开放数据格式的说明见 [DATA_FORMAT.md](DATA_FORMAT.md)。

家谱往往包含仍在世成员的敏感信息。分享项目包、截图或同步仓库前，请先征得相关家庭成员同意，并确认分享范围。

## 获取有谱

发布版本可从本仓库的 Releases 页面下载；请选择与操作系统匹配的安装包。macOS 用户请根据设备选择 `aarch64`（Apple 芯片）或 `x64`（Intel 芯片）版本。

本项目目前未使用 Apple Developer ID 签名和公证，macOS 安装包使用 ad-hoc 签名。请只从本项目官方 GitHub Releases 下载并确认来源可信。

将“有谱”拖入“应用程序”文件夹后，如果 macOS 提示“App 已损坏”或无法验证开发者，请打开“终端”执行：

```bash
xattr -dr com.apple.quarantine "/Applications/有谱.app"
open "/Applications/有谱.app"
```

该命令只移除“有谱”的互联网下载隔离标记，不会关闭系统的全局 Gatekeeper。仅对从本项目官方 GitHub Releases 下载的安装包执行此操作。

Windows 安装包目前也未进行商业代码签名，安装时操作系统可能显示安全提醒。

重要资料建议保留至少一份独立备份，并在升级前导出 `.blp` 项目包。

## 参与项目

欢迎通过 Issue、Discussion 或 Pull Request 参与有谱，包括：

- 报告问题和不符合预期的操作。
- 提出真实的家谱整理场景与产品建议。
- 改进无障碍体验、文案、翻译和使用说明。
- 完善不同地区、文化与家庭结构的表达能力。
- 协助测试数据导入、备份、恢复与跨平台体验。

提交问题时，请使用虚构或脱敏的示例，不要上传真实家谱、私人附件、访问凭据或其他敏感信息。

## 项目原则

1. 本地资料优先于在线服务。
2. 用户可以完整导出并迁移自己的数据。
3. 不以“常见”为由拒绝真实存在的家庭关系。
4. 重要事实应当能够关联来源。
5. 破坏性操作必须清楚、可预期。
