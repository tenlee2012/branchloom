# PDF 字体

`NotoSerifCJKsc-Regular.otf` 为 Noto Serif CJK SC 2.003 的原始字体，按同目录 `OFL.txt`（SIL Open Font License 1.1）分发。应用离线嵌入字体子集；不依赖设备字体。

OFL 文本前的 Adobe 版权声明读取自该字体的 name 表。完整声明与许可可在“编印族谱 → 纸张与装订 → 内置字体许可”查看，也随 CLI 安装回执的 `thirdPartyNotices` 字段分发。

来源：https://github.com/notofonts/noto-cjk/tree/Serif2.003/Serif

下载：https://raw.githubusercontent.com/notofonts/noto-cjk/Serif2.003/Serif/OTF/SimplifiedChinese/NotoSerifCJKsc-Regular.otf
